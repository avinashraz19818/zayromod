KYA GALAT THA
--------------------------------------------------------------------
1) FROZEN SNAPSHOT OVERRIDE (main culprit)
   Router (`api/_router.php`) pehle DB table `api_responses` ka saved "API
   snapshot/override" use karta tha — aur wo LIVE balance handler se UPAR tha.
   Template import ke waqt wahan static JSON `enabled=1` ke saath save ho gaya:
        ThirdGame/RecoverSaasBalance        -> "balance": 4.45   (frozen)
        ThirdGame/GetARGameAndPlatWallets   -> 4.45 / 0.0        (frozen)
        Recharge/GetRechargeBasicInfo       -> frozen
        Home/Login                          -> frozen
   Result: live DB balance kabhi pucha hi nahi jata tha — har user ko same ya
   0 balance dikhta tha, game ke andar blank.

2) WRONG RESPONSE SHAPE — /ThirdGame/GetARGameBalance
   Backend:  {"data": 4.45}      (sirf ek number)
   Frontend: Wt.arGameBalance = data.arGameBalance || 0   -> hamesha 0
   (wallet + game-wallet balance isi field se aata hai)

3) USER RESOLUTION (cPanel pe common)
   Token match na hone par code "pehla user" (local_member) use kar leta tha,
   jiska game_balance DB me 0 tha. Apache/LiteSpeed kuch setups pe
   Authorization header drop kar dete hain -> isi liye balance 0/blank.
   Ab: Authorization / X-Authorization / token header + cookie + query/body
   sab check hote hain, aur token bheja gaya par match nahi hua -> guest (0).
   Kisi OR member ka balance/bet ab kabhi nahi dikhega (safety).

4) TRANSFER / RECOVER ke baad UI purana balance dikhata tha
   (static cache wapas hota tha -> ab fresh DB value).

FAQ
--------------------------------------------------------------------
Q: Balance-fix page pe "token: MISSING" dikh raha hai?
A: Us member ko app me ek baar logout/login karwa dein. Token DB me
   `api_users.token` me save hota hai; uske bina API member ko resolve
   nahi kar sakti, isliye balance 0 dikhta tha.

Q: Balance 0 hai par user ke paas paisa hai?
A: WinGo game sirf GAME wallet kharch karta hai. "walletBalance" me paisa hai
   aur "balance" 0 -> member ko app ke andar "Transfer to game wallet" karna
   hai (ye correct behaviour hai, bug nahi).

Q: Purane override rows delete karne hain?
A: Zaroorat nahi — `enabled=0` hi kaafi hai, aur code inhe money endpoints pe
   kabhi use hi nahi karta ab.

Q: Security?
A: `admin/balance-fix.php` admin login ke bina kuch bhi nahi dikhata (403
   jaisa login form). Kaam ke baad ye file delete kar sakte hain — app iske
   bhi 100% chalega. Koi database schema change nahi kiya gaya.

Q: Update ke baad site crash ho jaye to?
A: Zip me se 2 files (`api/_bootstrap.php`, `_bootstrap.php`) hatake apne
   purane files wapas rakh dein — bas, site pehle jaisi. Tool/notes se kuch
   nahi todta.
